¿Que es GiHub? GitHub ed una plataforma en la nube que permite a los desarrolladores almacenar, gestionar y colaborar en proyectos de código fuente utilizando el sistema de control de versiones Git. 
¿Que espero aprender al utilizar repositorios? Yo espero aprender conceptos es esenciales, asi como à crear espacios de trabajo (locales y remotos) donde se almacena todo el historial y los archivos de mis proyectos.
